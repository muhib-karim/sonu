Dictate into any app. Local transcription by default.

SONU is a free, open-source voice typing app for Windows, macOS and Linux. Press a shortcut, speak, and your words are typed into whatever you are using, transcribed on your machine by Parakeet, Whisper or Moonshine.

Why SONU

Local by default

Transcription runs on your device. No account, no subscription, no audio uploaded unless you turn on a cloud engine.

Live preview

Text appears in the overlay while you speak, then a final pass replaces it.

Types anywhere

Browser, IDE, email, Slack, Discord, Word: anywhere you can type.

Model-dependent languages

Supported languages depend on the selected model. Test the language and audio you need.

Context-aware (Windows)

With AI clean-up on, adapts tone to the app you are typing in.

Optional AI clean-up

Optional text cleanup sends text to the remote OpenAI-compatible provider you configure.

Privacy

Stays on your machine

  • Audio and transcripts. Recording, voice detection and transcription run locally.
  • History. A local database and optional recordings, with a retention setting.
  • API keys. Kept in the OS credential store, never in the settings file.
  • No telemetry. No analytics, crash reporting or usage tracking in the code.

Uses the network

  • Model downloads, checksum-verified before use.
  • The update check against GitHub releases. On by default, can be turned off; updates are signature-verified.
  • Cloud transcription and AI clean-up, only if you enable them and add your own key.

Verify your download

Check the file against the release's SHA256SUMS, then confirm with the GitHub CLI that it was built by this repository's release workflow:

sha256sum --check --ignore-missing SHA256SUMS      # macOS: shasum -a 256 -c SHA256SUMS
gh attestation verify SONU_2.7.0_amd64.deb --repo muhib-karim/sonu

macOS builds are ad-hoc signed and Windows installers are not code-signed yet, so your OS will ask for confirmation on first launch.

Built in the open

Every pull request builds the real installers on all three platforms, runs the Rust and TypeScript test suites, a transcription regression on real speech, CodeQL and a secret scan.

SONU is a fork of Handy by CJ Pais (MIT). The README lists what this fork adds.
